# Bank Account Simulator (Java)

A console-based **Bank Account Simulator** written in Java, focusing on **core programming fundamentals, correctness, and clean procedural design**.  
This project is intentionally built step-by-step and will evolve over time into an object-oriented and backend-ready system.

📍 **Domain-inspired by Frankfurt’s banking and financial ecosystem**

---

## 🎯 Project Goal

The goal of this project is to:
- Strengthen Java fundamentals
- Practice clean procedural programming
- Model basic banking rules with correctness and safety
- Prepare a solid foundation for refactoring into OOP and Spring Boot

This version (**v1-procedural**) focuses on **logic, flow, and validation**, not frameworks.

---

## 🧩 Features (v1 – Procedural)

- Create a single bank account
- Deposit money with validation
- Withdraw money with balance protection
- Check account balance and details
- Menu-driven console interface
- Defensive input handling (no crashes on invalid input)

---

## 🛡️ Business Rules Implemented

- An account must be created before any transaction
- Deposit amount must be positive
- Withdrawal amount must be positive
- Withdrawal cannot exceed current balance
- Invalid inputs are handled gracefully

These rules reflect **basic financial system safety constraints**.
